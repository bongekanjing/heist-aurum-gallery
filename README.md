The Aurum Gallery: a top-down stealth heist you can play in the browser. You are a thief crossing a
guarded gallery at night. Three patrol guards and two sweeping ceiling cameras watch the floor. Cross
their cones and the alarm climbs; hit the top and the run ends. Take the emerald from the display
case, reach the service hatch, and get out.

Everything is canvas 2D with no dependencies: guards, cameras, thief and HUD are drawn from shapes.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```

To rebuild the screenshots and the source dossier the way the bounty harness does:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
